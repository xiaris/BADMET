# BADMET

**B**lack hole **AD**aptive **M**ulti-relation Mass **E**stimation based on **T**iming Analysis

BADMET estimates black hole masses from variability timescales and other empirical indicators.

## Demo

➡️ **[View the worked example](demo.ipynb)**

The notebook demonstrates mass inference using:

- DRW variability timescale
- X-ray luminosity
- Normalized excess variance
- A combination of all three indicators

## Quick start

```bash
git clone https://github.com/xiaris/BADMET.git
cd BADMET
python -m pip install -r requirements.txt
jupyter lab demo.ipynb
```
